# dmn Provider

The dmn provider evaluates DMN (Decision Model and Notation) decisions from standard `.dmn` files via the `provider::dmn::evaluate` function. Use it for multi-input, policy-driven lookups authored in a portable, standard format.

For a trivial single-key lookup, a native Terraform map (`lookup()` / `jsondecode(file(...))`) is simpler and preferred. Reach for this provider when the decision logic is genuinely multi-dimensional (ranges, multiple inputs, hit policies) or is owned and maintained outside the Terraform codebase in DMN tooling.

This provider exposes only a function; it has no resources or data sources and requires no configuration. Requires Terraform >= 1.8 or OpenTofu >= 1.7.
